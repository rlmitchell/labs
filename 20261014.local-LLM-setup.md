# Setup your own private LLM server

### Requirements
**Hardware:**

Any hardware you'd like to use that has enough memory to support the model gguf file.

- This write-up uses:
  ```
  1 old PC
    64gb DDR4 memory 
    AMD Ryzen 5 2600 Six-Core 12 Threads
    32gb storage for OS
    128gb storage for models and toold
  ```
  
**Operating System and Build Dependencies**

**Base OS**: Ubuntu 26.04.1 LTS (Resolute Raccoon)

- Verify the installed OS version:
  ```
  grep -i '^VERSION=' /etc/os-release
  ```
- Install the required build dependencies:
  ```
  sudo apt update
  sudo apt install -y build-essential cmake libssl-dev
  ```

&nbsp;
