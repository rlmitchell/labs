# Create a GGUF from a LLM on HuggingFace

### Requirements
**Hardware:**

Any hardware you'd like to use that has enough memory to support the model gguf file. I recommend a dedicated machine, even better would be in an isolated VM.

- This write-up uses:
  ```
  1 old PC
    64gb DDR4 memory 
    AMD Ryzen 5 2600 Six-Core 12 Threads
    32gb storage for OS
    128gb storage for models and tools
  ```
  
**Dependencies**:

This process uses the huggingface-cli and llama.cpp on Ubuntu 26.04:

```
u1@mimas:~$ grep VERSION= /etc/os-release
VERSION="26.04.1 LTS (Resolute Raccoon)"
u1@mimas:~$ 
```

- hf
```
u1@mimas:~$ ~/.local/bin/hf version

```

- llama.cpp

**Create a gguf file from the downloaded model**

The convert_hf_to_gguf.py script is provided by llama.cpp.

```
u1@mimas:~/ai/llama.cpp$ MODEL="$HOME/.cache/huggingface/hub/models--Qwen--Qwen2.5-0.5B-Instruct/snapshots/7ae557604adf67be50417f59c2c2f167def9a775"
u1@mimas:~/ai/llama.cpp$ python3 convert_hf_to_gguf.py "$MODEL" --outfile "$HOME/ai/models/Qwen2.5-0.5B-Instruct-f16.gguf" --outtype f16
```
